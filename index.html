Ajuda
Guia rápido

  
Criar o token

  
  1. GitHub, Settings, Developer settings
  2. Personal access tokens, Fine-grained tokens
  3. Repository access: só os repositórios desejados
  4. Permissions, Contents: Read and write
  5. Gere e cole na aba Enviar

  
Fluxo

  
  1. Conecte e escolha repositório e branch
  2. Escolha a pasta de destino
  3. Adicione arquivos, pasta, zip ou código do Editor
  4. Confira NOVO ou SUBSTITUI e envie

  
Problemas

  
  1. Erro 401 ou 403: token sem permissão no repositório
  2. Erro 409: repositório vazio, crie um commit inicial
  3. Qualquer erro de código aparece numa faixa vermelha no topo
