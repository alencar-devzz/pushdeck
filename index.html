Ajuda

Criar o token

  1. GitHub, Settings, Developer settings
  2. Personal access tokens, Fine-grained tokens
  3. Repository access: so os repos desejados
  4. Permissions, Contents: Read and write
  5. Gere e cole na aba Enviar

Fluxo de uso

  1. Conecte e escolha repo e branch
  2. Escolha a pasta de destino no menu
  3. Adicione arquivos, pasta, zip ou codigo do Editor
  4. Confira NOVO ou SUBSTITUI e envie

Problemas comuns

  1. Botoes nao respondem: veja a faixa vermelha no topo, ela mostra o erro
  2. Erro 404 ou 403: token sem permissao no repo escolhido
  3. Erro 409: repo vazio, crie um commit inicial
  4. Atalhos no computador: Ctrl+Enter envia, barra foca o filtro, 1 a 7 trocam de aba
